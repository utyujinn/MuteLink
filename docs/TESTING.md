# 動作確認の方針

このプロジェクトには自動テストが存在しない(ユニットテスト・統合テストいずれも無し)。
CIも「ビルドしてインストーラを作る」ところまでで、テスト実行は含まない。実装が正しいかどうかは
以下の方法で確認する。

## 実装直後、毎回やること

- **Rust**: `cargo check`(`tauri-src/src-tauri/`で実行)。フルビルドより速く、型・借用エラーは
  これで十分検出できる。挙動を実機で確かめる必要がある変更のみ `cargo build`/`bun run tauri dev`
  まで行う。
- **JS**: `node --check tauri-src/src/main.js` で構文エラーだけは機械的に検出する
  (Windows形式のパスで渡すこと、[docs/CODING_RULES.md](CODING_RULES.md)参照)。
- **I18N**: 文言キーを追加・変更したら、HTML側の `data-i18n` 参照とJS辞書のキーが一致しているか
  確認する([docs/CODING_RULES.md](CODING_RULES.md) のI18N節のワンライナー参照)。

## ビルドが通ってもそれだけでは完了にしない

`cargo check`/`node --check` は「壊れていないか」の最低ラインでしかなく、「意図通り動くか」は
別。UI/挙動が絡む変更は、変更内容をユーザーに説明した上で、実際に `bun run tauri dev` を再起動
して動かしてもらい、確認を得てから完了とする。特に以下は必ず実機確認が要る:

- 音声認識・TTS周り(実際に喋ってみないと分からない)
- VRオーバーレイ・ホットキー(SteamVR実機、コントローラー入力が要る)
- インストーラ/アンインストーラ(`cargo tauri build` → インストール → 起動 → アンインストールの
  一連の流れを実際に通す。`bundle.resources` の変更(モデル同梱等)は特に、開発環境では動いても
  配布ビルドでパスが解決できず失敗することがあるため要注意)

## 「フリーズしているように見える」不具合の調査手順

このセッションで実際に有効だった手順:

1. Rust側の各ステップに一時的に `eprintln!` を仕込み、`bun run tauri dev` を動かしている
   ターミナル(アプリ内の `#log` パネルとは別)に出力させ、Rust側が本当に最後まで到達しているか
   を確認する。到達していれば原因はJS側かIPC層。
2. JS側にも同様に、各ステップの直前直後で `log()` (アプリ内 `#log` パネル)を仕込む。
3. `Get-Process -Name "tauri-src"` (PowerShell)で `.CPU` を一定間隔で比較し、CPU使用率が
   増え続けているか(単に遅いだけ)、増えていないか(本当に停止している)を切り分ける。
   `.Responding` はOSレベルの基本的な応答性チェックで、これがTrueでも上位のロジックが
   止まっていることはある。
4. 上記で「Rust・JSどちらのログも最後まで出ているのに画面が変化しない」場合、IPCの問題ではなく
   見た目の問題(CSSで実際には要素が隠れていない等)を疑う。このセッションでは実際にこのパターン
   だった(`[hidden]` が `.settings-list-row`の`display: flex`に負けていた)。
5. 原因特定後、デバッグ用に仕込んだ `eprintln!`/`log()` は必ず削除する。

## 手動テストチェックリスト(実機が必要なもの)

- [ ] 音声認識(Web Speech API / SenseVoice / Whisper 切り替え含む)で実際に発話し、テキスト化
      されることを確認する
- [ ] VOICEVOXでの読み上げがVB-Audio Virtual Cable経由でVRChat側に届くことを確認する
- [ ] VRChatのチャットボックスへのOSC送信が届くことを確認する
- [ ] SteamVR起動状態でVRオーバーレイ・コントローラーホットキー(確認/送信/破棄/言語切り替え)が
      動作することを確認する
- [ ] デスクトップモード(SteamVR無し)でも同等の操作ができることを確認する
- [ ] インストーラでの新規インストール・アップデート・アンインストールが正常に完了することを
      確認する(`bundle.resources` に変更があった場合は特に)
